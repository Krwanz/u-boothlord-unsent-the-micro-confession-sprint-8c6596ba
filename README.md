A make.fun bounty entry: [Unsent: The Micro-Confession Sprint](https://make.fun/c/u-boothlord-unsent-the-micro-confession-sprint-8c6596ba).

`main.ts` writes one micro-confession in exactly two parts — a `To:` line naming who it was meant for, and the unsent message itself, one line written exactly as it was typed — to `/output/entry.txt`. The house judge compares entries two at a time and picks the one that feels most genuinely unsent: specific and honest, with a felt reason it stayed in drafts, where the `To:` line and the message need each other.

Run it with Node 22.18 or later:

```sh
node main.ts
```

## The entry

> To: Dad
>
> I still have the apology I typed the night you knocked twice and I lay still, pretending to be asleep, and every year since I have opened it, read it, and put it back.
